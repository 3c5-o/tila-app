# تِلا — Tila

تطبيق وموقع عربي لإنشاء تصاميم التلاوات القرآنية باحترافية.

- واجهة RTL داكنة بهوية زمردية.
- اختيار القارئ والصورة والسورة والآيات.
- قوالب متعددة وتعديل الصورة والألوان.
- إنشاء غلاف وصفحات آيات تلقائيًا.
- تصدير PNG بمقاسات بوست/ستوري/مربع.
- حفظ المشاريع محليًا.
- نسخة Android تحفظ الصور داخل `Pictures/Tila`.
- نسخة Web/PWA قابلة للنشر على GitHub Pages.

> المستودع قيد البناء.
